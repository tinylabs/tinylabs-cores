Due to licensing restrictions, download the ARM AT421 package here:

https://support.arm.com/downloads/view/AT421?sortBy=availableBy&revision=r0p0-02rel0-1

Save it as AT421-r0p0-02rel0-1.tar.gz in this directory. FuseSoC will unpack it,
apply the local compatibility patches, and verify the required RTL files when
the cm3_obs core is used.
